Cosine Search: direction beats distance

How Sentinel finds the closest fraud-case text among 3,072-dimensional vectors · scripts/cosine_search.py

The idea in one picture

The formula

cos(a, b) = a · b / (|a| |b|)

1 = same direction · 0 = unrelated · -1 = opposite. Vector length is ignored.
